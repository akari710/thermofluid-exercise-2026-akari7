# N02 学習ログ

## 予想と式・コード

- N01の一定速度移流との違い、左側の広がりと右側の急峻化の予想：N01は速度が一定（c=1）であるため，波形全体が同じ速さで+x方向へ移動したが，N02のBurgers方程式では特性速度が u に依存する．矩形波の左端では高い値ほど速く右へ進み，波が広がる．右端では速い高値が遅い低値に追いつき，波が急峻化する．
- 保存形の流束差分と非保存形の差、式・配列・添字の対応：保存形は u_t + f(u)_x = 0，f(u)=u²/2 である．後退差分と陽Euler法による更新は u_new[i] = u_old[i] - (dt/dx) * (f(u_old[i]) - f(u_old[left]))．配列添字 i は格子点を表し，「left」は i の左隣である．固定境界では内部点のみ更新し，周期境界では先頭の左隣を末尾として全点を更新する．保存形は隣り合う点の流束差を使うため，周期境界で全点を足し合わせると流束項が相殺し，離散総和が保存される．非保存形 u_t + u*u_x = 0 を差分化した式とは一般に離散計算が同じにならず，特に不連続波の扱いに違いが出る．
- 固定／周期の格子、周期添字、境界、バッファ交換の説明：固定境界は nx=81 とし，両端を含む [0,2] を dx=2/(nx-1)=0.025 で分割する．周期境界は nx=80 とし，終点2を重複させず dx=2/nx=0.025 とする．周期添字は i=1 のとき左隣を n，それ以外は i-1 とする．固定境界は左端を1.0にし，右端を左隣の値にする．周期境界の境界処理は配列を変更しない．各ステップで旧配列から新配列へ計算し，境界処理後に u_old, u_new = u_new, u_old と交換するので，次のステップも更新前の場を参照できる．

## 結果と解釈

- nx、dx、steps、dt、指定CFLと実効最大CFL：指定CFL=0.5，t_final=1.0．固定境界は nx=81，周期境界は nx=80，どちらも dx=0.025，steps=160，dt=0.00625，max_cfl=0.5．
- 初期・最終極値、オーバーシュート・アンダーシュート：初期値は両ケースとも最小1.0，最大2.0．固定境界の最終値は最小1.0，最大1.4942095043070338，overshoot=0.0，undershoot=0.0．周期境界の最終値は最小1.0000002582164118，最大1.8163945680355078，overshoot=0.0，undershoot=0.0．いずれも初期値の範囲 [1,2] を外れなかった．
- 周期の初期総和・最終総和・符号付き変化量：初期総和=101.0，最終総和=101.00000000000003，符号付き変化量=2.842170943040401e-14．この小さな差は浮動小数点演算の丸め誤差と考えられる．
- N01との比較に用いた判定量・判定条件と根拠：必須テストでは，速度1で単純移動した矩形波 「shifted」 と最終解との差を離散L1量 「dx * sum(abs.(u - shifted))」 で測り，固定・周期の両方で 0.2 より大きいことを確認した．これは，N02の解がN01の一定速度移流のような単純な平行移動だけでは説明できない程度に変形したことを確認する判定である．あわせて x>1.5 の領域で u の最大値が1.2を超えることを確認した．N01の既存結果は nx=81，dx=0.025，CFL=0.5，t=0.5（40 steps，dt=0.0125）であり，N02は t=1.0 なので，数値を直接比較するのではなく，速度一定と速度がuに依存する場合の違いを比較した．

## 必須4群と自作2つのテスト

- 配布された必須テストの入力・期待値・判断条件を確認し，その意味を説明：必須テストは4つ．(1) 「burgers_flux(1)=0.5`，`burgers_flux(2)=2」 と周期左隣の例を確認し，流束式と添字を検査する．(2) 周期配列 [1,2,1,1] を dt=0.25，dx=1 で1ステップ進め，期待値 [1,1.625,1.375,1] と一致すること，旧配列が変わらないことを確認する．(3) 固定境界の定数場1と周期境界の定数場0.7が更新後も保たれること，固定境界適用後 [4,2,3,8] が [1,2,3,3] になることを確認する．(4) 固定81点・周期80点のシミュレーションで max_cfl<=0.5+1e-14，最終値が概ね[1,2]内，速度1の移動矩形との離散L1差が0.2より大きいこと，x>1.5での最大値が1.2より大きいことを確認する．これらは流束・周期添字・更新式・配列保持・境界処理・CFL・波形変形をそれぞれ検査する．
- 自作1（周期総和保存）：入力、ステップ数、期待値、許容誤差とその根拠：入力 [0.2,1.0,0.4,0.0,1.8,0.7,0.1,0.5]，周期境界，dt=0.02，dx=0.1 で20ステップ計算する．期待値は計算後の総和が初期総和と近似的に等しいこと．判定は isapprox の atol=1e-10，rtol=1e-10 とする．8点・20ステップの浮動小数点丸め誤差を許容しつつ，総和保存を壊す実装誤りを検出できる精度として設定した．
- 自作1で検出できる誤り／できない誤り：周期境界の端点添字や流束差分の誤りなど，総和を変化させる不具合を検出できる．一方，総和を保存したまま誤った値を各点に割り振る実装や，局所的な波形の誤り，固定境界でのみ起きる不具合は検出できない．
- 自作2（循環移動と更新の整合）：非対称な入力 `[0.2,1.3,0.0,0.7,2.1,0.4,0.9,0.1]` を使い，k=3，要素数8，周期境界，dt=0.02，dx=0.1 とする．入力を先に3要素循環移動して1ステップ更新した結果と，元の入力を更新してから結果を3要素循環移動した値が近似的に一致することを確認する．判定は atol=1e-10，rtol=1e-10．周期格子上の更新は格子の位置を循環移動しても同じ規則で行われるため，浮動小数点誤差を許しつつ添字の取り違えを検出する設定である．
- 自作2で検出できる誤り／できない誤り：先頭・末尾の周期添字の誤りや，点によって異なる更新処理が入る不具合を検出できる．一方，すべての点で同じ誤った式を使う実装や，総和保存の違反を必ず検出するものではないため，自作1や必須テストと合わせて使う．
