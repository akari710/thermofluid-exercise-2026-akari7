## 結果と解釈

- nx、dx、dt、steps、指定と実効Fourier数：標準計算ではnx=81，dx=0.025，dt=0.0025，steps=400，終了時刻 t_final=1.0であった．指定Fourier数は0.4，実効Fourier数は0.3999999999999999．終了時刻に整数ステップで到達するために実効値が調整されている．
- 両境界の初期・最終熱量、符号付き変化、全時刻の極値：初期熱量は両境界とも0.525．
  固定温度では最終熱量0.461840713264037，符号付き変化-0.06315928673596305．
  断熱では最終熱量0.5249999999999999，符号付き変化-1.1102230246251565e-16で，丸め誤差の範囲で保存された．
  全時刻を通した温度の最小値と最大値は，両境界とも0.0と1.0だった．今回の標準条件では温度範囲を逸脱しなかった．

- 数値：[summary.toml](results/summary.toml)
- 同時刻・同じfoの格子収束、誤差・観測次数、時間1次と合成誤差2次の違い：固定温度の正弦モードを使いt_final=1.0，指定fo=0.4，拡散係数0.1でnx=41, 81, 161を比較した．格子幅は0.05, 0.025, 0.0125，最大絶対誤差はそれぞれ1.3889713139303428e-4，3.4695215399116464e-5，8.671989364383847e-6だった．格子を半分にするごとに誤差は約4分の1となり，観測次数は約2.0012と2.0003だった．
陽Euler法の時間誤差は一般に1次、中心差分の空間誤差は2次である．ただしこの比較ではFourier数をほぼ一定にしているため，dtはdx^2に比例して小さくなる．したがって時間1次の誤差もdxに対しては2次相当となり，空間誤差と合わせた誤差が約2次に見える．この結果だけから時間積分法自体が2次精度だとは言えない．
- N01・N02の数値拡散と物理拡散の違い、予想との比較、限界：N01・N02の移流計算では，風上差分などの離散化によって波形が広がることがあり，これは連続方程式に拡散項がない場合にも数値計算で生じる数値拡散である．一方、N03では方程式に熱拡散項があり，温度分布が広がるのはモデルに含まれる物理的な拡散である．N03の数値解にも格子幅・時間刻みによる離散化誤差は残る．
固定温度では熱量が減り、断熱では保存されると予想し，標準結果はその予想と一致した．格子収束でも誤差は減少した．ただし，確認した境界条件・格子・初期値の結果がすべての条件での挙動や精度を保証するわけではない．
- 任意実験を行った場合の条件、振動・増幅・初期範囲逸脱、安定性テストの適用範囲：今回，任意の不安定条件実験は実施していない．必須テストでは標準条件のFo <= 0.5，有限な計算結果、初期値の範囲からの逸脱がないことを確認した．これは標準計算での確認であり，Fo > 0.5の計算で振動・増幅や初期範囲からの逸脱が起きないことを保証するものではない．

## 必須4群と自作2つのテスト

- 配布済み必須4群の入力・期待値・判定の意味：
 1. 非対称配列[1., 2., 4., 3.]を断熱条件で1ステップ更新する．dt=0.25，dx=1，拡散係数1（Fo=0.25）で期待値[1.5, 2.25, 3.25, 3.5]と一致すること，および旧配列が変更されないことを確認する．内部点更新・断熱端更新と新旧バッファの分離を調べる．
  2. 断熱条件で定数0.7，固定温度条件で定数0の場が不変であることを確認する．また，固定温度条件で[1., 2., 4., 3.]を1ステップ更新すると[0., 2.25, 3.25, 0.]になることを確認する．定数場の保持と固定端処理を調べる．
  3. 台形則による熱量を確認する．[1., 2., 4., 3.]とdx=1の熱量が8であること，断熱更新後の[1.5, 2.25, 3.25, 3.5]も8であることを確認する．端点の半分の重みと熱量計算を調べる．
  4. 固定温度・断熱の標準シミュレーションを確認する．終了時刻1.0に到達すること，実効Fourier数が0より大きく0.5以下であること，温度が有限で，全時刻を通した範囲が[0, 1]内であることを確認する．標準条件での時間設定・安定条件・温度範囲を調べる。
- 自作1（断熱熱量保存）：非対称非定数配列、ステップ数、独立に求めた初期熱量、許容誤差と根拠：初期配列[0.2, 1.3, 0.5, 2.1, 0.8, 0.4, 1.7]，dx=0.1，拡散係数0.1，Fo=0.4，100ステップを使った．初期熱量はthermal_contentを使わず，dx * (old[1]/2 + sum(old[2:end-1]) + old[end]/2)で独立に計算した．初期の熱量計算と、各更新後の熱量を初期値と比較した．
  絶対許容誤差は100 * eps(Float64) * nsteps * scale`（`scale = dx * length(old) * maximum(abs, old)`）とした．点数・値のスケール・反復回数に応じた浮動小数点丸め誤差を見込み、相対許容誤差は使っていない．
- 自作1で検出できる誤り／できない誤り：断熱端の更新係数や熱量の計算に誤りがあり，台形則の熱量保存が崩れる場合を検出できる．一方，熱量を保存したまま局所的な温度分布を誤って更新する不具合や，固定温度条件だけで起きる不具合は，このテストだけでは検出できない．
- 自作2（正弦解析解と格子収束）：格子・時刻・fo，誤差指標，許容範囲と根拠：固定温度境界，nx=41, 81, 161，t_final=1.0，指定fo=0.4，拡散係数0.1を使用した．各格子の数値解を正弦モードの解析解と比較し，最大絶対誤差を指標とした．誤差が格子を細かくするごとに減少すること，誤差が浮動小数点丸めだけで偶然0になるのではないこと，観測次数が各段階で1.8より大きく2.2より小さいことを判定した．理論的に期待する約2次精度を含む範囲として設定した．
- 自作2で検出できる誤り／できない誤り：この格子・時刻・Fourier数における正弦モードの更新式や境界処理の誤り，または期待される格子収束から外れる実装を検出できる．一方，正弦モード以外の初期条件・境界条件，別の格子幅や時間刻みでの問題を網羅するものではない．また，Fourier数を固定したこの比較だけでは時間誤差と空間誤差を分離して評価できない．
